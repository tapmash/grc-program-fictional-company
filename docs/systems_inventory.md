# Bright Bean Coffee — Systems Inventory (Step 1)

| System | What it does | Main users (roles) | 
| ----- | ----- | ----- | 
| **Microsoft Entra ID (Identity Service)** | Central identity directory managing user accounts, authentication passwords, Multi-Factor Authentication (MFA), and Single Sign-On (SSO) policies. | All office staff, managers, administrative staff, and IT administrators. | 
| **Microsoft 365** | Enterprise email (Exchange), team collaboration (Teams), file storage & intranet (OneDrive, SharePoint), and office productivity software. | All office staff, managers, and administrative roles across all sites. | 
| **Windows Workstations** | Local operating system running on company laptops and desktop PCs for daily business tasks and local software access. | Executive, Finance, HR, IT, Sales, Facilities leads, and Operations managers. | 
| **Endpoint Detection & Response (EDR / Antivirus)** | Endpoint security agent installed on all laptops and servers to detect, isolate, and respond to malware and malicious threats. | All workstation and server end-users (monitored by IT & MSP). | 
| **Mobile POS (Point of Sale)** | Tablet and terminal till application used for customer checkout, order entry, and daily sales logging. | Branch Managers, Branch Supervisors, Senior Baristas, Baristas / Cashiers, Canteen Supervisor, Systems Administrator, and IT Support Technician (Branch). | 
| **Card Payment Terminals (EFTPOS)** | Standalone and integrated payment card readers processing credit and debit card transactions at checkout points. | Baristas / Cashiers, Canteen Supervisor, and Branch Staff. | 
| **CartSmartz Seller Portal** | Web portal provided by CartSmartz for managing online store product listings, pricing updates, seller dashboards, payout reconciliations, and order overrides. | E-Commerce Sales Coordinator, Key Accounts Manager, Head of International Sales, and Accounts Receivable & CartSmartz Reconciliation Specialist. | 
| **CartSmartz Sync API** | Custom automated integration script syncing stock levels and incoming online sales orders between CartSmartz and the central database. | E-Commerce Integration Specialist, Systems Administrator, and IT Manager. | 
| **Central Inventory & ERP Database** | Core relational database tracking green coffee bean stock, finished product batches, warehouse levels, and branch inventory allocations. | Systems Administrator, Warehouse Manager, Inventory Control Clerk, Master Roaster, and Packaging Line Supervisor. | 
| **Warehouse & Dispatch System** | Barcode scanning and shipping label generation software for local courier dispatch and regional distribution tracking. | Warehouse Manager, Dispatch Clerk, Receiving & Inbound Goods Clerk, and Logistics Drivers. | 
| **Export Documentation Portal** | Specialized web service used to generate, log, and submit international shipping manifests, bills of lading, and export compliance documents. | Export Documentation Clerk, International Dispatch Clerk, and Head of International Sales. | 
| **Cloud Accounting Software** | Core financial accounting platform handling general ledger, invoicing, accounts payable/receivable, bank reconciliations, and financial reporting. | Senior Accountant, Accounts Payable Officer, Accounts Receivable & CartSmartz Specialist, Financial Analyst, and CEO. | 
| **Payroll & HR Portal** | Cloud platform managing employee salaries, tax deductions, leave requests, employee records, and payslip distribution. | Payroll Administrator, HR Manager, HR Officer, and all staff (self-service leave). | 
| **Corporate Internet Banking** | Online commercial banking portal for processing inward foreign payments, batch EFT supplier payouts, and branch cash drop reconciliations. | CEO, COO, Senior Accountant, and Accounts Payable Officer. | 
| **Enterprise Password Manager** | Centralized, encrypted password vault for securely storing, sharing, and auditing corporate credentials and vendor portal logins. | All office staff, line managers, and IT personnel. | 
| **IT Service Desk / Ticketing Portal** | Standardized ticketing platform for submitting, tracking, and approving IT access requests, equipment issues, and JML onboarding tickets. | All company employees (ticket submitters), Internal IT Team, and MSP Support Staff. | 
| **Network & Firewall Infrastructure** | Physical and virtual firewalls, core switches, and managed Wi-Fi access points securing corporate and branch network traffic. | IT Manager, Systems Administrator, IT Support Technician (Branch), and MSP Support Engineers. | 
| **Remote Monitoring & Management (RMM)** | Endpoint management tool used by the MSP to deploy software patches, track hardware health, and run background management scripts. | MSP Support Engineers and Primary MSP Account Engineer. | 
| **Secure VPN Gateway** | Encrypted tunnel allowing remote and field staff to connect securely to internal network resources, files, and central databases. | Internal IT Helpdesk Technician, Systems Administrator, Head of International Sales, Regional Sales Representatives, Key Accounts Manager, Corporate Accounts Manager, Regional Branch Operations Manager, National Training Barista, and MSP Engineers. | 
| **Microsoft Azure Cloud Platform** | Cloud infrastructure host running virtual machines, central SQL database servers, storage buckets, and daily automated cloud backups. | MSP Support Engineers, Systems Administrator, and IT Manager. | 
| **Roastery Control Software** | Specialized machine control interface connected to industrial coffee roasters for managing roast profiles, thermal curves, and batch logs. | Master Roaster, Production Floor Supervisor, and Assistant Roaster. | 
| **Automated Packaging Line PLC** | Touchscreen interface on the packaging line for weight calibration, pouch sealing, and date stamping. | Packaging Line Supervisor and Packaging Machine Specialist. | 
| **Physical Access Control & CCTV** | Keycard/fob door readers, biometric scanners, and IP security cameras for building security, loading dock monitoring, and restricted site areas. | All Cape Town Head Office Staff, Canteen Staff, Warehouse Personnel, Facilities Staff, Security Personnel, and Escorted Visitors/Vendors. | 
| **Vehicle Fleet Tracking System** | Telematics GPS portal for monitoring real-time locations, fuel efficiency, driver security, and delivery routes of transport vehicles. | Primary Logistics Driver, Local Fleet Drivers, Gauteng Hub Driver, and Warehouse Manager. |
