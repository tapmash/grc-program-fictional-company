| **Central Inventory & ERP Database** | Core relational database tracking green coffee bean stock, finished product batches, warehouse levels, and branch allocations. | Systems Administrator, Warehouse Manager, Inventory Control Clerk, Master Roaster, and Packaging Line Supervisor. | Chief Operating Officer (COO) | In-House IT (Systems Administrator) |
| **Warehouse & Dispatch System** | Barcode scanning and shipping label generation software for local courier dispatch and regional distribution tracking. | Warehouse Manager, Dispatch Clerk, Receiving & Inbound Goods Clerk, and Logistics Drivers. | Warehouse Manager | In-House IT (IT Support Technician - General Helpdesk & Systems Administrator) |

| **Corporate Internet Banking** | Online commercial banking portal for processing inward foreign payments, batch EFT supplier payouts, and branch cash drop reconciliations. | CEO, COO, Senior Accountant, and Accounts Payable Officer. | Chief Executive Officer (CEO) | Chief Executive Officer (CEO); Senior Accountant (Secondary Approver / Bank Admin) |
| **Enterprise Password Manager** | Centralized, encrypted password vault for securely storing, sharing, and auditing corporate credentials and vendor portal logins. | All office staff, line managers, and IT personnel. | IT Manager | In-House IT (Systems Administrator); Muza IT (Vault Backup & Policy Admin) |
| **IT Service Desk / Ticketing Portal** | Standardized ticketing platform for submitting, tracking, and approving IT access requests, equipment issues, and JML onboarding tickets. | All company employees (ticket submitters), Internal IT Team, and MSP Support Staff. | IT Manager | In-House IT (Systems Administrator & IT Support Technician - General Helpdesk); Muza IT (Tier-3 Integration Support) |
| **Network & Firewall Infrastructure** | Physical and virtual firewalls, core switches, and managed Wi-Fi access points securing corporate and branch network traffic. | IT Manager, Systems Administrator, IT Support Technician (Branch), and MSP Support Engineers. | IT Manager | Muza IT (Network & Firewall Lead Engineers); In-House IT (Systems Administrator - Read-Only / On-Premise Escorts) |
| **Remote Monitoring & Management (RMM)** | Endpoint management tool used by the MSP to deploy software patches, track hardware health, and run background management scripts. | MSP Support Engineers and Primary MSP Account Engineer. | IT Manager | Muza IT (Primary RMM Tenant Administrator) |
| **Secure VPN Gateway** | Encrypted tunnel allowing remote and field staff to connect securely to internal network resources, files, and central databases. | Internal IT Helpdesk Technician, Systems Administrator, Head of International Sales, Regional Sales Representatives, Key Accounts Manager, Corporate Accounts Manager, Regional Branch Operations Manager, National Training Barista, and MSP Engineers. | IT Manager | Muza IT (VPN & Infrastructure Administrator); In-House IT (Systems Administrator - User Account Binding) |
| **Microsoft Azure Cloud Platform** | Cloud infrastructure host running virtual machines, central SQL database servers, storage buckets, and daily automated cloud backups. | MSP Support Engineers, Systems Administrator, and IT Manager. | IT Manager | Muza IT (Global & Cloud Infrastructure Administrator); In-House IT (Systems Administrator - Database Service Admin) |
| **Roastery Control Software** | Specialized machine control interface connected to industrial coffee roasters for managing roast profiles, thermal curves, and batch logs. | Master Roaster, Production Floor Supervisor, and Assistant Roaster. | Master Roaster | Master Roaster (System Admin & Profile Lead); Maintenance Technician (Hardware & Sensor Calibration) |
| **Automated Packaging Line PLC** | Touchscreen interface on the packaging line for weight calibration, pouch sealing, and date stamping. | Packaging Line Supervisor and Packaging Machine Specialist. | Production Floor Supervisor | Production Floor Supervisor; Packaging Machine Specialist |
| **Physical Access Control & CCTV** | Keycard/fob door readers, biometric scanners, and IP security cameras for building security, loading dock monitoring, and restricted site areas. | All Cape Town Head Office Staff, Canteen Staff, Warehouse Personnel, Facilities Staff, Security Personnel, and Escorted Visitors/Vendors. | Facilities Maintenance Lead | Facilities Maintenance Lead (Badge & Door Access Manager); Grounds & Security Supervisor (CCTV System Admin) |
| **Vehicle Fleet Tracking System** | Telematics GPS portal for monitoring real-time locations, fuel efficiency, driver security, and delivery routes of transport vehicles. | Primary Logistics Driver, Local Fleet Drivers, Gauteng Hub Driver, and Warehouse Manager. | Warehouse Manager | Warehouse Manager (Telematics Portal Admin); Fleet Tracking Service Provider (Vendor Support Admin) |
